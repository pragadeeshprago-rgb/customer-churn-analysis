3. Cleaning Decisions and Assumptions

  • Trimmed leading/trailing whitespace and converted blank strings to missing values.
  • Standardized known case/spelling variants in category labels.
  • Converted tenure, senior-citizen indicator and charge columns to numeric types.
  • Removed exact duplicate rows.
  • Treated SeniorCitizen values outside 0/1, negative tenure and negative charges as invalid/missing.
  • Imputed numeric missing values with the median and categorical missing values with the mode. This is a simple educational baseline.
  • Used the 1.5×IQR rule to flag numeric outliers. Outliers were reported rather than automatically removed because extreme charges can be valid.

4. Validation Checks

Cleaned dataset: 240 rows × 14 columns. Checks passed: no missing cells; no duplicate rows; SeniorCitizen restricted to 0/1; tenure and charges non-negative; churn labels restricted to Yes/No.
